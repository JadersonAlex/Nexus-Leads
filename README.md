# Nexus-Leads

**Sistema de gerenciamento de leads e oportunidades comerciais.**

O Nexus-Leads é uma aplicação desenvolvida para facilitar a organização e o acompanhamento de leads, negócios, notas e informações comerciais, oferecendo praticidade e controle em um só lugar.

## ✨ Funcionalidades

- Cadastro e gerenciamento de leads e negócios.
- Registro de notas e acompanhamento de etapas comerciais.
- Salvamento automático dos dados no navegador.
- Exportação e restauração de backups em formato JSON.
- Opções para substituir ou mesclar dados durante a restauração.
- Indicador de status do backup e alertas em caso de falha no salvamento.

## 💾 Armazenamento de dados

Atualmente, os dados são armazenados localmente no navegador utilizado. Por isso, recomenda-se realizar backups periódicos para evitar a perda de informações.

**Importante:** os dados não são sincronizados automaticamente entre diferentes navegadores ou dispositivos.

## 🚀 Próximas evoluções

O Nexus-Leads poderá evoluir para atender às necessidades de empresas, com recursos como:

- **Armazenamento em nuvem:** acesso aos dados a partir de diferentes dispositivos.
- **Sincronização de dados:** atualização das informações entre usuários autorizados.
- **Gestão empresarial:** estruturação de bases comerciais para equipes e organizações.
- **Controle de acesso:** gerenciamento de permissões conforme o perfil de cada usuário.

Essas funcionalidades fazem parte da evolução planejada do projeto e poderão ser implementadas futuramente.
